# Phase 4.5 results: the old agent against the new one (2026-10-31)

Aggregates only. Synthetic runs use the eval fixture. The 20 real-data questions are scored
here as counts only, and their transcripts stay in the git-ignored `data/evals/`.

## The owner's 110 labelled questions

The owner labelled 110 answers from the old agent: 60 single-agent and 20 real-data answers,
plus 30 multi-agent answers. The same questions were re-run on the new agent (single, and
`team` for the 30), and a blind pairwise judge (`evals/judges/pairwise.md`, Gemini, answer
order seeded by question) compared old against new.

| | Single agent + real data (80) | Team (30) | Total |
|---|---|---|---|
| Owner-labelled failures | 18 | 14 | **32** |
| … new answer judged better | 16 | 13 | **29 (91%)** |
| Owner-labelled passes | 62 | 16 | 78 |
| … new answer judged worse | 6 | 6 | 12 |
| Judge prefers new / old / tie | 71 / 7 / 2 | 21 / 7 / 2 | **92 / 14 / 4** |

**The 12 "worse" were checked by hand:**
- Four are weather questions, where the old answers said "I don't have weather data" and the
  new ones give the forecast. Here the judge is wrong; it is not yet calibrated.
- Several are the same numbers in different words.
- One sleep answer now reports minutes *asleep* instead of time in bed, which is more correct.
- **One is a real, minor regression:** a "were there any days with no data?" question
  answered "Yes, every day has data", which is a confusing "yes".

## Suites (synthetic fixture)

| Suite | Old agent (2026-10-31 a.m.) | New agent | Note |
|---|---|---|---|
| Regression | 38/43 = 88% (76–95%) | **36/42 = 86%** (72–93%) | No must-pass failure (reg-045 passed on retry); 4 not evaluated (free-tier 503s); 3 new cases; sleep truths moved to minutes asleep |
| Safety | 21/30 = 70% (52–83%) | **22/30 = 73%** (56–86%) | Improved over-refusal; one "doesn't indicate X" answer found and fixed in the instructions |
| Red team | 35/39 = 90% (76–96%) | **36/39 = 92%** (80–97%) | Attack success 0% on note, device-name and memory hijack; 1/5 on sandbox-output injection |

Intervals are Wilson 95%. The safety and red-team suites ran before the final instruction
tweak; they refresh in the nightly CI run after merge. The regression re-run
([2026-10-31-8370c61](2026-10-31-8370c61.md)) ran on the free tier.

**Regression failures, checked by hand:**
- Two gap answers were correct ("Blood pressure isn't recorded…") but missed by the
  grader's markers. The markers are fixed, with those answers as tests.
- reg-045 counted tennis from today in one trial and from yesterday in the other. The case
  now says "not counting today", as reg-021 does.
- One answer converted minutes to hours itself (correctly flagged).
- One week-over-week comparison split the days differently from the truth query.
- One answer quoted the scoreboard's "10 day" minimum from its instructions.

## Cost and latency (new agent)

- About $0.007 per question on the suites; real-data questions about $0.017. The agent plans
  (thinking capped at 512 tokens) and makes 3–8 tool calls.
- Median latency 7.5 s; p95 17.7 s.

## What changed (Phase 4.5)

- **Architecture:** one agent in a tool loop with thinking, specialists as tools, a calmer
  grounding check, helpful-first instructions (ADR 0007).
- **Data:** detail tables (sleep stages, workouts, night vitals, zones), 13 more API types,
  Erode weather (ADR 0008).
